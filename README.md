# 飞花令 Feihua-Ling

MaiBot 飞花令插件：bot 有一份不会遗忘的「已用诗句清单」，接令时绝不重复任何人——包括它自己。

## 为什么需要它

MaiBot 的回复上下文只有最近几十条消息。飞花令玩上十几轮，早期诗句就滚出了 bot 的记忆，它会把别人甚至自己说过的诗句再说一遍，游戏很难完整进行。

本插件替 bot 记住**所有**已用诗句（群友、bot 自己、群里其他 bot 说的都算），并在 bot 每次生成回复前把完整清单注入它的上下文——从第一句到最后一句，一句都不会忘。

## 特性

- **重复当场提醒**：谁说了别人说过的诗句，立刻点名
- **繁简互通**：繁体的「春眠不覺曉」和简体的「春眠不觉晓」互相判重
- **半句也算重复**：整句和其中的分句互相判重
- **重启不丢局**：游戏记录持久化；MaiBot 重启后正在玩的局照常继续，早已超时的局自动静默清理，不打扰群聊
- **可选 bot 主动接令**：开启后每 N 条玩家诗句，bot 自动作诗一句（默认关闭，bot 只在被点名时接令）
- **插件级开关**：不用飞花令时一键关闭，不产生任何消息

## 命令

| 命令 | 说明 |
|------|------|
| `/fhl` | 开局，从令字池随机抽取（花 月 风 雪 春 江 水 山） |
| `/fhl <字>` | 开局并指定令字，如 `/fhl 花` |
| `/fhl end` | 结束本局，发战报排行（`/fhl stop` 同义） |
| `/fhl status` | 查看当前局进度 |
| `/fhl history` | 查看本群上一局战报（`/fhl last` 同义） |
| `/fhl help` | 用法说明 |

## 游戏示例

```text
> /fhl 花
🎋 飞花令开局！令字：「花」
规则：说一句含「花」字的真实古诗词（4~20 字），整句或半句说过都算重复；10 分钟无新诗句自动收官。
来吧，说出含「花」的诗句，bot 也会接令～

> 花间一壶酒            （张三先说，正常入账）

> 花间一壶酒            （李四跟了重复句）
🚫「花间一壶酒」这句 张三 已经说过啦，换一句吧～

> /fhl end
🌸 飞花令「花」收官！共 12 句诗，历时约 8 分钟
🏅 排行：
1. 张三 ×5
2. 李四 ×4
3. bot ×3
```

## 安装

- **插件市场（推荐）**：MaiBot WebUI → 插件管理 → 插件市场，搜索「飞花令」一键安装
- **手动安装**：从 [Releases](https://github.com/ValleyWinds/Feihua-Ling/releases) 下载最新版本，解压到 MaiBot 的 `plugins/` 目录，在 WebUI 插件管理中重新加载即可生效，无需重启

## 配置

在 MaiBot WebUI 的插件配置页调整，全部有默认值、可零配置开玩：

| 配置 | 默认 | 说明 |
|------|------|------|
| 启用飞花令 | 开 | 插件总开关；关闭后不记录、不注入、不提示 |
| 超时收官（分钟） | 10 | 一局多少分钟没有新诗句后自动静默收官 |
| 枯竭提示线（条） | 50 | 已用诗句超过此数后，提醒 bot 该令字诗句可能已枯竭、建议收官 |
| bot 主动接令 | 关 | 开启后每累计 N 条玩家诗句，bot 自动作诗一句 |
| 主动接令间隔（条） | 5 | 与上一项配合使用 |
| bot 重复提示 | 开 | bot 说了重复诗句时是否当场提示（罚酒一杯） |
| 随机令字池 | 花 月 风 雪 春 江 水 山 | 开局未指定令字时的随机池 |

## 已知限制

- 诗句识别基于文本规则（含令字的 4~20 字短句），插件不验证诗句真伪—— bot 可能对出不存在的"诗句"
- 繁体判重覆盖常用字，个别冷僻繁体字可能漏判
